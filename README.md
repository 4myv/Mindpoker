# 마인드 포커

Tmax IT 희망학교 NEXT AI 과정의 과제로 만든 웹 카드 게임입니다.
과제는 **Skill과 하네스를 적용해 에이전트를 만들고, 그 에이전트를 활용해 기초 게임을 만드는 것**이었습니다.

🎮 [바로 플레이](https://4myv.github.io/mindpoker/마인드포커.html) · 📣 [홍보 페이지](https://4myv.github.io/mindpoker/)

## 게임 소개

- 인디언 포커를 바탕으로 한 1:1 심리전 카드 게임 (플레이어 vs AI)
- 내 카드는 볼 수 없고 상대 카드만 보여서, 상대의 베팅을 보고 내 카드를 추측해야 합니다.
- 특수 규칙: 10을 들고 폴드하면 벌금으로 칩 3개를 상대에게 줍니다.

## 실행 방법

`마인드포커.html` 파일 하나로 동작합니다. 위의 링크로 바로 플레이하거나, 파일을 내려받아 브라우저로 열면 됩니다.
